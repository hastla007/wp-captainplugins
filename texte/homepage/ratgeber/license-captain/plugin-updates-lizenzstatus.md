# Plugin-Updates mit Lizenzstatus und Berechtigungen steuern

Ein kommerzielles Plugin benötigt einen klaren Zusammenhang zwischen Kauf, Lizenz und Updatezugriff. License Captain verwaltet diese Informationen zentral und stellt eine signierte API für Ihre Produkt-Plugins bereit.

## Berechtigungen definieren

Ordnen Sie einem Lizenzplan Entitlements zu. Damit bestimmen Sie, welche Produktfunktionen und Leistungen für den jeweiligen Plan verfügbar sind.

## Client-Integration passend zum Produkt wählen

License Captain stellt die Server-API bereit. Ihr Produkt-Plugin kann den Client nach der dokumentierten Schnittstellenspezifikation direkt integrieren. Alternativ können Sie die Verbindung über ein separates Client-Plugin bereitstellen. In beiden Fällen fragt die Integration Lizenzstatus und Berechtigungen über signierte Requests und Responses ab und behandelt Fehlerfälle verständlich.

## Releases bereitstellen

Verwalten Sie Produktversionen und Updatepakete über den Lizenzserver. Kunden mit gültigem Updatezugriff erhalten die für ihr Produkt vorgesehenen Updates.

## Release-Notizen sichtbar machen

Changelogs können pro Produkt in Kundenkonten oder auf Dokumentationsseiten eingebunden werden. So sehen Anwender, welche Änderungen ein Release enthält.
