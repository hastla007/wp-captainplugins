## Bildbriefing

Jeder Platzhalter nennt Motiv, relevante UI-Elemente und Datenschutz-Hinweise. Für echte Aufnahmen eine Testinstallation verwenden, private Schlüssel, Kundendaten, E-Mail-Adressen, Bestellnummern und Zahlungsdaten entfernen und die Ansicht für Desktop sowie Mobilgerät prüfen.
