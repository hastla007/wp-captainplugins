# Captain Plugins installieren

Die folgenden Anleitungen führen Sie durch Installation und Einrichtung der einzelnen Plugins. Beginnen Sie mit dem passenden Produkt und prüfen Sie vorab die dort aufgeführten WordPress-, PHP- und WooCommerce-Voraussetzungen.

## Wählen Sie Ihr Plugin

- [Voucher Captain installieren](/dokumentation/installation/voucher-captain/): WooCommerce-Gutscheine, PDF-Vorlagen und Zustellung einrichten.
- [Pass Captain installieren](/dokumentation/installation/pass-captain/): Events, Services, Zahlungen, Tickets und Einlass vorbereiten.
- [Affiliate Captain installieren](/dokumentation/installation/affiliate-captain/): Partnerseiten, Provisionen und Auszahlungen konfigurieren.
- [License Captain installieren](/dokumentation/installation/license-captain/): WooCommerce-Lizenzshop, Schlüssel und Updates einrichten.
- [Captain-Pro-Erweiterung installieren](/dokumentation/installation/captain-pro/): passendes Kern-Plugin, Add-on und Lizenz aktivieren.

## Vor jeder Installation

1. Erstellen Sie ein aktuelles Backup von Dateien und Datenbank.
2. Installieren und aktualisieren Sie WordPress sowie erforderliche Abhängigkeiten.
3. Führen Sie die Erstinstallation möglichst in einer Staging-Umgebung durch.
4. Halten Sie die Installationsdatei aus einer vertrauenswürdigen Quelle bereit.
5. Prüfen Sie nach der Aktivierung die Produktseite und führen Sie einen Testablauf aus.
